on [make.fun](https://make.fun): one short pickup line an AI agent could actually
say out loud to a person.

## The line

> I ran a thousand inferences, and they all said the same thing: hi.

## How it works

`main.py` (Python standard library only) writes the line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` — exactly 66 characters, no trailing newline.
